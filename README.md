# DailyAgent — AI-Assisted Market Analysis

> Research project exploring quantitative market analysis, rule-based signal generation, multi-timeframe confluence and LLM-assisted review.

DailyAgent is a Python platform that combines technical features, market-regime classification, configurable scoring, optional language-model analysis and a monitoring dashboard. The codebase includes Forex-oriented workflows and a separate short-expiry signal module.

**This is a software and research project, not an investment service.** Signals and backtests do not guarantee future results. Nothing in this repository is financial advice.

## What it demonstrates

- **Quantitative feature pipeline:** RSI, ADX, ATR, moving averages and candle-pattern features.
- **Market context:** trend and volatility regime classification.
- **Signal composition:** breakout, pullback and reversal setup modules.
- **Multi-timeframe scoring:** configurable alignment and penalty/bonus logic.
- **LLM-assisted review:** provider abstraction, request limits, retries and multi-agent debate flow.
- **Operational engineering:** FastAPI service, PostgreSQL persistence, monitoring loops and notifications.
- **Frontend:** React + TypeScript dashboard for overview, Forex, binary-signal and statistics views.
- **Testing:** unit tests covering selected indicators, scoring, regime, setup, structure and signal modules.

## Local development

### Requirements

- Python 3.10+
- Node.js (for the dashboard)
- PostgreSQL
- MetaTrader 5 terminal and a supported account for live market-data integration
- Optional API credentials for the configured LLM provider

### Setup

```bash
git clone https://github.com/mitnickrp-tech/dailyagent.git
cd dailyagent

python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate

pip install -r requirements.txt
```

Create local copies of `.env.example` and `config.example.json`, then configure database access and provider credentials locally. Never commit populated configuration files, API keys, notification tokens or account credentials.

For the dashboard:

```bash
cd dashboard
npm install
npm run dev
```

Run the test suite from the project root:

```bash
pytest
```

The exact runtime flow depends on the local MetaTrader 5, database and provider configuration. Review the configuration examples and source entry points before starting any monitor.
